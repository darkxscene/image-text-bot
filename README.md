Telegram-Бот для автоматического наложения текста на изображения

Полностью готовый и рабочий чат-бот, написанный на Python, который принимает от пользователя текстовую строку, а затем накладывает её на присланную фотографию, центрируя текст и обеспечивая читаемость на любом фоне.

Технический стек
* Язык: Python 3
* Библиотеки: Pillow (обработка графики), pyTelegramBotAPI (интерфейс Telegram API)

Основные возможности
* Автоматическое масштабирование шрифта под любое разрешение исходного изображения.
* Двухслойный рендеринг (белый текст с черной обводкой) для идеальной читаемости на светлом и темном фоне.
* Модульная архитектура: код легко переносится на корпоративные платформы (например, мессенджер MAX) при наличии соответствующих токенов доступа.

Как запустить локально
1. Установите библиотеки: pip install pillow pyTelegramBotAPI
2. Вставьте ваш API токен в переменную TOKEN в файле main.py
3. Запустите скрипт: python main.py
